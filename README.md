# Exercícios de Estrutura de Dados em C

Repositório com exercícios desenvolvidos durante meus estudos de Estrutura de Dados na graduação em Engenharia de Software.

O objetivo é praticar a linguagem C e compreender o funcionamento das estruturas de dados.

## Exercício disponível

### Fila

Implementação de uma fila com a lógica **FIFO — First In, First Out**: o primeiro elemento inserido é o primeiro a ser removido.

O programa permite:

- Inserir elementos na fila.
- Remover elementos da fila.
- Verificar se a fila está cheia.
- Verificar se a fila está vazia.

## Tecnologias utilizadas

- Linguagem C.
- Code::Blocks como ambiente de desenvolvimento.

## Como executar

1. Baixe o arquivo `.c` do exercício.
2. Abra o arquivo no Code::Blocks.
3. Compile e execute o programa usando **Build and Run**.

É necessário ter um compilador C configurado no computador.
